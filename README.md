# Tech Oreon Analytica

**Shaping greatness with data**

Tech Oreon Analytica is a Nairobi-based research, polling, market intelligence and data systems firm. We help campaigns, institutions, brands and development partners turn raw public signals into structured, decision-ready intelligence.

## Company profile

Tech Oreon Analytica brings together research depth, field execution, digital intelligence and modern reporting workflows built for Kenyan realities. Our work is designed for clients who need more than raw data. We focus on clear evidence, explainable analysis and outputs that leadership teams can act on quickly.

We work across public opinion, market research, customer intelligence, field data systems and digital monitoring, combining human research judgement with technology-enabled delivery.

## Core capabilities

- Public opinion research and perception tracking
- Market research and brand positioning
- Opinion polling and message testing
- Digital intelligence and social listening
- Customer experience analysis
- Customer service intelligence workflows
- Field data systems, dashboards and quality control
- Data labelling, synthesis and executive reporting

## Solution areas

- **Marketing**: brand tracking, message testing, segmentation, affordability work and launch diagnostics
- **Risk & Compliance**: narrative monitoring, conduct coding, misinformation tracking and escalation reporting
- **Customer Experience**: journey mapping, pain-point analysis, satisfaction tracking and service comparison
- **Customer Service**: unified feedback handling, priority labelling, response support and management dashboards

## How we work

- **Capture the signal** through phone interviews, WhatsApp, SMS, field CAPI, digital listening and other structured inputs
- **Apply context-specific labels** so messy feedback becomes meaningful and comparable
- **Validate the evidence** using quality checks, weighting logic, callbacks and analyst review
- **Deliver for action** through dashboards, briefs, maps, trend summaries and leadership-ready recommendations

## This repository

This repository contains the Tech Oreon Analytica website, built as a responsive React application with Vite and Tailwind CSS.

### Local development

```bash
npm install
npm run dev
```

### Production build

```bash
npm run build
```

### Deployment

The site is configured for Vercel deployment, including SPA route handling through `vercel.json`.
